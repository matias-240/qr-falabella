# QR Falabella (dinámicos)

Los códigos QR apuntan a páginas de redirección en GitHub Pages. Para cambiar el producto de destino, edita la variable `DESTINO` en `balloon/index.html` o `envolvente/index.html`; el QR no cambia.

- Balloon: https://matias-240.github.io/qr-falabella/balloon/
- Envolvente: https://matias-240.github.io/qr-falabella/envolvente/

Regenerar QR: `npm install && node generate.js`
